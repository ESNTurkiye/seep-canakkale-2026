# Source photographs

Drop each Organising Committee member's original photograph here as
`<slug>.jpg`, where the slug matches `content/oc.ts` — e.g. `berkay-kiran.jpg`.

These are inputs, not outputs. They are never published: the site reads only
`public/portraits/<slug>.png`, which is what the model produces from them.

The photograph standard, and why it matters more than the prompt, is in
[`docs/art-direction.md`](../../docs/art-direction.md).

Nobody's photograph goes in here without them knowing, and nobody's portrait
goes live without them approving it — see
[`docs/adr/0002-ai-generated-oc-portraits.md`](../../docs/adr/0002-ai-generated-oc-portraits.md).
